I built Langur to learn how to write a chatbot. You chose two languages, sent it a message, and got the translation back in the same conversation.

I used [Node.js](https://nodejs.org/), the [Microsoft Bot Framework](https://dev.botframework.com/), and a [Google Translate library](https://github.com/matheuss/google-translate-api). I later published the [source on GitHub](https://github.com/arshad115/langur-translation-bot) and wrote up [how to run it in the Bot Emulator](/development/my-first-open-source-repository-langur-translation-chat-bot/).
