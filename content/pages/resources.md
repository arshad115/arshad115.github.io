These are tools I use in day-to-day engineering. The list follows the work, so older Android libraries stay further down.

## Development Tools

### Backend and infrastructure
- **[Go](https://go.dev/)** — the language I use for cloud-native services
- **[Kubernetes](https://kubernetes.io/)** — where those services run
- **[Docker](https://www.docker.com/)** — local containers and images
- **[Linux](https://www.kernel.org/)** — the operating system underneath the rest

### Notes and editing
- **[Obsidian](https://obsidian.md/)** — the notebook behind Today I Learned and [Vault Linker](https://github.com/arshad115/vault-linker)
- **[VS Code](https://code.visualstudio.com/)** — editor
- **[Git](https://git-scm.com/)** — version control

### Earlier Android work
- **[Android Studio](https://developer.android.com/studio)** — IDE for the apps in the portfolio
- **[Kotlin](https://kotlinlang.org/)** — the current Android language

## Books worth rereading

- **Clean Code** by Robert C. Martin
- **The DevOps Handbook** by Gene Kim
- **Effective Java** by Joshua Bloch
